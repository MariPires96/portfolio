# Portfólio – Atividade do Bootcamp Generation Brasil

Este projeto foi desenvolvido como parte do **Bootcamp da Generation Brasil em Desenvolvimento Full Stack JavaScript**, com o objetivo de praticar os conceitos básicos de **HTML5** e **CSS**.

## 📌 Objetivo
Desenvolver uma página web simples para exercitar:
- Estruturação de conteúdo com HTML5
- Uso de tags semânticas
- Estilização com CSS
- Organização de arquivos do projeto

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3

## 🚀 Como visualizar o projeto
- Abrindo o arquivo `index.html` diretamente no navegador  
- Ou utilizando a extensão **Live Server** no VS Code
